Privacy Policy — ANAS AI Encrypted Backups

Effective date: 10 October 2026. Operator and privacy contact: Anas Shalash, annsshalash@gmail.com. This is a personal-use ANAS AI tool, independent of NOVA.

Google data and purpose

The app requests only https://www.googleapis.com/auth/drive.file. It checks the connected Google Drive account email and creates, downloads and manages app-created encrypted backup files. It does not request access to all Drive files. Account checks restrict accepted connections to the personal owner.

Storage and safeguards

OAuth refresh grants are encrypted server-side with a dedicated key. Access tokens are used transiently for API requests. Backup contents are encrypted before upload to personal Google Drive; recovery keys must be held separately. Secrets, tokens and backup bodies are excluded from application diagnostics.

ANAS AI infrastructure processes requests using Vercel and its configured ANAS-only session storage. Google stores encrypted files in the owner's Drive. No data is sold, used for advertising, or shared with NOVA. Google user data is used only to provide this backup function, in accordance with the Google API Services User Data Policy, including Limited Use requirements.

Retention and control

The intended backup retention is 14 days. Scheduled real backups and provider retention are not active yet; this policy does not claim existing Production protection. The accepted synthetic test file was moved to trash. Moving files to trash is not permanent deletion and may continue to consume storage.

Google authorization can be revoked from the owner's Google Account third-party connections. Revocation stops future API access but does not automatically delete existing files or encrypted stored grants. Contact the operator to request deletion of app-held authorization data; backup files can also be removed by their owner in Drive. No automatic deletion deadline is claimed until the retention mechanism is activated.
